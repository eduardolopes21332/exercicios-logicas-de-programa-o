# 🧠 Exercícios de Lógica de Programação — C#

Coletânea de exercícios de **lógica de programação** resolvidos em **C#**, da graduação em Sistemas de Informação (UNISANTA).

## 📂 Exercícios

| Arquivo | O que faz |
|---|---|
| `exercicio01-par-ou-impar.cs` | Lê um número e diz se é par ou ímpar |
| `exercicio02-calcula-media.cs` | Calcula a média de 3 notas e mostra aprovação |

## ▶️ Como rodar

Cada arquivo é independente. Com o [.NET SDK](https://dotnet.microsoft.com/download) instalado:

```bash
dotnet run exercicio01-par-ou-impar.cs
```
